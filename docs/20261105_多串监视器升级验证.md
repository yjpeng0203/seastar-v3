# 多串监视器升级与验证（2026-11-05）

本次实现后台三串持续处理、快速历史回放、持久化细分箱、全宽缩略总览与近全屏详情，以及趋势右侧共享 y 轴的分布。相对采集时间保持原样；北京时间仅在轴下作为分钟级参考，不进行跨串同步、符合或时空联合分析。

## 最新确认的时间显示规则

按本轮最后确认实现：时间分箱可主动设置，默认开启且箱宽 **100 s**；点击“应用时间分箱”才应用新箱宽。可取消勾选切回逐条原值。两种模式都按采集顺序连接相邻有效点，缺失值不补 0。

- 分箱模式：每箱按原始记录的和与有效数量计算均值；质量标记显示箱内通过比例，事件/波形间隔显示箱内平均间隔，均不伪装为瞬时 Hz。完整时段直接读取保存的逐波形指标计算，**不从旧 100 秒均值再次合并**。
- 原值模式：保留各条观测的时间和值、相邻原始时间戳之差及 0/1 标记；大范围采用有明确前后页的原值分页，不抽点或取平均。
- 右侧数值分布独立于时间分箱：分箱模式统计所选完整时段的原始值，原值模式统计当前原值页。改变时间箱宽不改变同一时段原始分布计数；读数上下限和数值 bin 数在详情中另行设置。
- 分箱模式图内缩放只改视野，不重新定义时间箱。要改变统计时段，使用采集秒范围并应用；原值页图内时间缩放可直接统计已有原始点。
- 首次更换时间箱设置需扫描标量指标并保存独立缓存；页面显示耗时，不重新积分原始波形。G5 全量 100 s 首次约 **21.2 s**，26,148,761 条记录生成 4,437 组通道/事件箱统计，原始电荷分布仍计入全部 26,148,761 条。

## 后台与性能

- 默认 `--workers 3`，每串独立进程/状态目录，切换查看对象不关闭其他读取器。父服务和各 SQLite 状态使用独占锁。关闭服务会回收子任务；父进程异常退出时子任务也停止。
- 同串在线优先 DAT，历史回放优先完整 ROOT，避免一份采集重复分析。历史结果复用前校验输入大小/修改时间、参数和内核指纹；保存结果缺失时复用原 C++ 内核批处理。
- DAT 以 4 MiB 为批次，数值内核批量调用；细分箱索引与逐波形指标、统计、断点同事务提交。旧指标可一次建立索引。自定义标量查询按水位增量更新缓存，各图独立查询锁。
- 机械盘 DAT 按批次轮转读取；原生历史批处理采用 8192 事件批次的共享磁盘锁。NVMe 可并读。历史任务降低 CPU 调度优先级。
- 正常本机启动不再先扫描整批 DAT；完整体检保留为 `--verify-only`。Linux 调试脚本默认将缓存放到用户缓存目录，`SEASTAR_STATE_DIR` 可覆盖。

以下在本机 Mac 测得，**不是工控机实测**；已有有效分析及显示缓存：

- 三串全部就绪：1.358 秒。
- 切串接口：0.045–0.049 秒，保留其他串任务。
- 默认电荷谱预览接口：0.030–0.032 秒。
- G3 首次自定义 0–4000 ADC·sample、4000 bins 查询约 2.317 秒，不重新积分波形。
- 无缓存的完整 ROOT 需要首次 C++ 分析；进度、吞吐和估计剩余时间显示在任务卡片。未完成缓存不冒充完整结果，失败后安全重建；已完成标量结果与显示缓存可分别复用。DAT 保留逐批事务恢复。

## 图形与统计口径

- 幅度 1 ADC/bin、积分 1 ADC·sample/bin；默认配置转换后为 0.5 mV/bin、0.02 pC/bin。单位切换不改箱数、计数与统计样本。
- 缩略图只作显示层峰值预览，不对相邻箱求和。省略的箱不代表零；详情加载完整细箱。最后一排卡片也铺满横向空间。
- 详情提供适用的单位、样本类型、通道、范围/bin、logY、归一化、图例、缩放和 PNG 导出；关闭后保留设置。
- logY 相邻正计数箱连接为阶梯，只在零箱间断开。孤立非零箱保留像素标记，零不填假值；归一化后小于 1 的概率正常显示。
- 右侧为原始观测的数值分布，与时间箱均值独立；两侧共享读数 y 轴。数值范围和 bin 数可在详情主动设置。
- 当前实现按原始指标重新计算用户指定的时间箱，默认 100 s，也可切回逐条原值。不是复用旧均值表再次求平均。
- 北京时间参考来自同串 CSV 的主机时间与 FPGA 计数对应记录，剔除明显偏离的锚点；缺少可用锚点时提示缺失。每分钟刷新参考，既不改原时间，也不承诺同步精度。
- 旧版 v1 浏览器自定义分箱不再自动套用；v2 手动设置继续保留，避免旧 1 pC/bin 遮盖新默认。手动自定义上限仍为 4096 bins；默认细箱不受此限制，图形缩放不改变细箱。

## 使用

```sh
# 本机或历史批次；正常启动不再先进行整批体检
sh scripts/debug_local.sh /数据集目录 --open

# 工控机在线，原始数据目录按实际情况填写；状态建议放 NVMe
sh data-ana-monitor/online/start.sh --data-dir /原始数据目录 \
  --state-dir /home/ipc/.cache/seastar-v2/analysis --workers 3 --open
```

部署时保留原数据、配置和状态目录，覆盖程序后重启并刷新网页。旧的单源 SQLite 不删除；新多串状态放在 `strings/` 下。复用历史标量文件时，未保存的 `polarity`、`baseline_points` 在 CSV 中留空；示例波形原采集时刻未知时显示“—”，不填造数据。


## 默认纵轴修正

默认共享 y 轴已改为按当前趋势点范围加少量留白，避免原始记录极值压扁 100 s 均值；合格比例默认 0–1。详情增加“原值全范围 / 按趋势范围”切换，原始分箱和计数均不改变。视窗外可确定计数和跨边界箱的不确定记录数分别标明。

G5 实机网页验证：基线默认约 162.157–224.990 ADC，噪声约 0.8913–1.1648 ADC；基线切原值全范围后约 −123.35–2744.35 ADC，返回趋势范围即时恢复。新增检查覆盖原值极值、常量/小范围趋势、合格比例自然范围、两侧坐标对齐、全范围往返及计数/曲线不变性。


## Hz 与统计误差带更新

主概览已将间隔图替换为 Hz：彩线按通道波形 N/实际观测箱长计算，黑线按带波形事件数/箱长计算，右侧也为 Hz 数值分布，横轴标“时间箱数”。绝不使用平均间隔倒数冒充箱计数率。G5 首 100 s：CH 0=1610/100=16.1 Hz，CH 1=104.71 Hz，CH 2=170.17 Hz；全范围波形计数求和 26,148,761，事件求和 24,690,815，与保存的 ROOT 计数一致。默认100 s读取保存的整数计数约 0.009 s，无需等待其它均值误差重建。

灰带默认启用：率为 68.27% Poisson 区间（小计数精确，大计数近似），均值为±样本标准误，比例为 Wilson 68.27% 区间。CH 0 首箱约 [15.6988,16.5113] Hz。零计数保留上限；均值有效 N<2 时不填零误差。均值每箱 M2 从原始指标累计，不由分布箱中心反推。切换单位同步缩放误差上下界。原始 ADC 分箱和物理量换算规则保持不变。

新增4项计数率测试覆盖实际曝光、零箱、末箱、筛选、冻结水位、独立事件去重、原生 ROOT 对照和区间数值；Poisson近似及Wilson结果已对照本机ROOT分位数/TEfficiency。波形监视器测试合计50项通过；前端覆盖误差带开关、两侧对齐、Hz、自动范围及原始曲线/计数不变。

误差仅含所述统计模型，假设观测独立，不含仪器系统误差。多通道同图时灰带可能很窄，不做人为放大；实际浏览器已验证单通道 Hz 灰带及隐藏事件曲线后的自动范围，控制台无错误或警告。
