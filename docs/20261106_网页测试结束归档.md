# 波形监控网页：测试结束后一键归档

## 使用

1. 保持原有方式启动波形监控，例如 `sh scripts/start_ipc.sh`。
2. 本轮测试结束、所选 DAT 不再写入后，打开“测试结束 · 数据归档”页。
3. 页面默认选择最新一轮的 Run；确认串、保存目录和慢控制 CSV 目录。批次名称可留空，自动按采集日期命名。
4. 勾选“本轮测试已结束，所选数据不再写入”，点击“开始归档”。环境检查会随开始操作自动执行，也可提前点击“检查环境”。
5. 页面显示当前阶段、处理对象、用时和最终保存位置，以及各串 ROOT、CSV 明细。CSV 不匹配或数据不完整会明确提示。

不再需要单独输入 decoder、hadd 或 organizer finalize 命令。高级 decoder 路径默认沿用已修正的 `../../build/decoder` 和 `../../cfg/config.json`；相对路径以本机原始 DAT 目录为基准。

## 归档内容

每串形成 `批次/Gx/raw_data`、`rec_data`、`csv`：

- 波形 DAT 按卷解码，包含已经停采的末卷；复用已有验证通过的分卷检查点。
- 同串同 Run 的 ROOT 合并并核验事件数与首末触发。
- 原始波形 DAT 复制到归档目录；匹配同板号、同 Run 的 trigger_signal 旁路文件也原样复制并登记 SHA-256，不送入波形解码器。
- 匹配慢控制 CSV 的时间区间，保存切片及对应说明。
- 生成 manifest.json 与 SHA256SUMS.txt，再检查批次结构、ROOT 计数和全部文件的 SHA-256。

源 DAT、触发旁路及 CSV 不移动、不删除、不 chmod。归档文件为独立副本，归档后的原始数据副本及结果文件按既有规则设为只读。分析结果仍由原有分析流程写入 Gx/results；一键归档不自动启动耗时的离线分析。

## 运行约束与恢复

- 实时监控与归档使用独立进程。归档中页面保持响应，采集数据源和分析参数不因归档而切换。
- 缺少中间分卷、末卷仍在写入、未确认停采时拒绝归档。
- 归档前后再次比较所选 Run 的完整文件清单、大小、mtime 和权限，覆盖新增卷、删除及变化；发现变化不标记成功。
- 同板多个 Run 的分钟级时间范围重合时，ROOT/CSV 名称增加 Run 标识，避免同名覆盖。
- 工作目录加独占锁；旧 organizer watch/finalize 未退出时显示冲突提示，不重复执行。
- 中断或失败不标记成功，已验证分卷检查点保留；重新启动同批次会复用这些分卷，不重复 decode。
- 页面保存归档路径和最近一次成功结果，重启服务后可查看。缺少 CSV 的批次在结果中显著列出提示。

## 部署更新

由用户自行部署，不通过向日葵操作。先结束旧的联调监视脚本和独立 organizer watch（DAQ采集进程保持运行）。将 `seastar-v2-web-archive-20261106.tar.gz` 放到 `~/SeastarMonitor_pyj` 后：

```sh
cd ~/SeastarMonitor_pyj
tar -czf "seastar-code-before-archive-$(date +%Y%m%d-%H%M%S).tar.gz" \
  --exclude=state --exclude=runtime --exclude=__pycache__ --exclude=build \
  seastar-v2/organizer seastar-v2/data-ana-monitor/online seastar-v2/scripts/start_ipc.sh
tar -xzf seastar-v2-web-archive-20261106.tar.gz
cd seastar-v2
sh scripts/start_ipc.sh
```

页面 Ctrl+Shift+R 刷新后可见新页签。更新包不覆盖 config/、fee-monitor/config.json、原始数据或状态目录。新版联调脚本不再额外启动独立 organizer watch，完整归档统一由网页在测试结束后触发。`--no-watch` 仅保留旧命令兼容性。

## 验收

本机通过 HTTP 和真实网页按钮完成三串各4 MiB真实波形样本的归档：每串4036波形，ROOT与CSV均生成，批次SHA及结构核验通过。旁路文件使用模拟字节验证原样保存。另通过真实4 MiB G3样本加一个停采末卷，验证实际 hadd、CSV切片、清单、SHA、源文件不变与重复归档复用。

现场的 decoder 二进制沿用现有版本；本机验收使用同一参数接口的原生C++测试解码器。本机测试不等同于已部署工控机。
