# FEE CSV 实时监测（Linux 工控机部署）

将本包部署在 Linux 工控机：工控机通过已有 SSH/SFTP 只读取得树莓派 CSV 的新增字节，保存本地镜像，浏览器读取镜像并计算、绘图。树莓派保持原采集程序，不需要运行本包、不需要图形界面，也不需要安装 Python 库。

工控机只需 Python 3.8+ 和系统 OpenSSH 客户端。图表库随包提供，无需 pip、Node.js、npm 或互联网。SSH 负责认证和加密，包内仅使用 SFTP v3 的只读文件及目录操作。

采集程序和 SSH 服务继续在树莓派运行；旧版监控 server.py 已不需要，可在它自己的终端按 Ctrl+C 停止。

## 在 Linux 工控机部署

以下命令都在工控机执行，不是在 SSH 登录后的树莓派终端中执行。

    tar -xzf fee-monitor.tar.gz
    cd fee-monitor
    sh start.sh --open

首次启动按提示填写树莓派 IP、SSH 用户名、端口和 CSV 路径。默认路径为截图中的 /home/pi/seastar-daq/fee-monitor/data，也可以填某一个 CSV 的完整路径。“登录方式”选择 1 或直接回车表示密码登录，2 表示 SSH 密钥；此处不是密码输入框。所有配置通过校验后才保存，随后会出现单独的“树莓派 SSH 密码”提示，输入不回显。密码只保留在进程内存，不写配置、不放进命令参数。断线重连会复用内存密码，程序重启需重新输入。

配置保存在工控机的 config.json，默认镜像存于 ~/.local/share/fee-monitor/mirror 下按来源区分的子目录，更新程序不会覆盖镜像。需要重新配置时运行 sh start.sh --setup --open。也可以参考 config.example.json 编辑非密码配置；禁止在配置中保存 password 字段。

启动后在工控机浏览器打开 http://127.0.0.1:8765。页面提供 FEE 选择框，默认“跟随所选 FEE 最新文件”；切换 FEE 即查看对应镜像。保持工控机监控进程运行，关闭浏览器不停止后台同步；Ctrl+C 停止服务和同步。源 CSV 继续保存在树莓派，由原采集程序管理。

首次 SSH 连接必须核实主机：先在工控机正常执行 ssh pi@树莓派IP，核对主机指纹并完成登录，再输入 exit 退出。本包使用系统 known_hosts 严格校验主机，不会自动信任未知或已变更的密钥。SSH 端口非 22 时使用 ssh -p 端口 用户名@树莓派IP。主机尚未确认、密码错误、源路径不存在等问题会显示在页面连接状态中。

如使用已有免密密钥，将 auth 设为 key；默认使用 SSH 配置和 agent，也可在 identity_file 填私钥路径。加密私钥请先加入本机 ssh-agent。树莓派现有 SSH 服务需要启用 SFTP 子系统；本包不会自动修改其 SSH 配置。

缺少命令时只需在工控机安装 python3 / openssh-client，例如 Debian/Ubuntu 的 sudo apt install python3 openssh-client。无桌面工控机可不加 --open，通过已有方式访问其服务；需要从另一台电脑访问时加 --host 0.0.0.0。默认仅监听工控机本机，端口占用可加 --port 8766。

## 树莓派负载控制

- 一个持续 SSH/SFTP 连接，不按每次刷新重复登录，不启用 SSH 压缩。
- 默认每 5 秒检查活跃 CSV 的属性；文件未增长时不重新打开或读取内容。目录每 30 秒扫描一次，单个 CSV 路径模式不扫描目录。
- 按 readback_fee_N.csv / readback_fee_N_日期.csv 识别 FEE，默认同步每个 FEE 各自最新的一份 CSV，以及运行后新出现的文件；不自动复制全部旧历史。无法识别 FEE 的其他 CSV 归为一组，各组分别取最新。
- 各 FEE 共用一个连接和 128 KiB/s 总限速，轮流取得数据；一份文件的历史补传不会长期阻挡其他 FEE 出现在页面中。仅查看 CSV，.dat 文件不读取或复制。
- 第一次完整读取选中的当前文件，随后从已落盘偏移量读新增字节；默认平均限速 128 KiB/s，每次最多读取 32 KiB。32 MiB 首次回补约需 4 分钟，实际还受网络和磁盘影响；补齐前页面明确提示尚未追上最新数据。
- 断点、状态、镜像和同步锁都写在工控机。对树莓派不创建镜像、状态文件或临时文件，不发送写入、删除、改名或强制落盘请求。
- 追加或重连时只读取少量边界内容校验续传，不反复全文件计算校验和。文件截断或边界内容变更时将旧镜像归档在工控机 .archive 下，再重新同步。

这减少的是监控带来的额外访问，不取消原采集程序的 SD 卡写入，也不保证树莓派操作系统日志或访问时间更新为零。目录请精确到实际数据目录，避免指向整个 /home 或系统根目录；每次最多遍历 128 个目录、深度最多 6 层。

## 同步与换文件

连接状态独立于图表刷新：显示最近成功检查时间、当前文件缓存进度、剩余待补字节和限速。断线时图表仍可查看已加载的本地镜像，但页面明确显示异常，不将本地读取成功当成树莓派在线。

发现新文件的延迟最多包含一次目录扫描间隔（默认 30 秒），活跃文件新增内容通常包含一次检查间隔（默认 5 秒）和页面刷新间隔。采集程序自身的写缓冲也会影响可见延迟。

每个 FEE 内按远端修改时间选择最新文件；时间相同时优先 readback_fee_N.csv，再按文件名排序。例如 readback_fee_3.csv、readback_fee_5.csv、readback_fee_7.csv、readback_fee_8.csv 会同时同步，带日期的旧文件默认不批量搬运。切换 FEE 后，其他 FEE 更新不会把页面跳走。

建议给每次采集使用唯一文件名，只追加，已结束文件保持不变。源文件仍保留时可以补传监控运行后出现的文件；首次启动前的旧历史默认不搬运。需要查看某份旧文件时可将 remote_path 指向该文件并重新启动。

源文件暂时消失时保留其本地缓存和进度，并继续同步可用的新文件；页面显示缺失提示。未补齐的源文件在树莓派上被删除后，缺少的内容无法凭空恢复。

同名原地修改且文件头尾恰好未变，或同大小改写发生在远端时间戳精度内，不能可靠识别；应使用新的文件名。新文件会保留独立镜像，不把不同批次直接拼接。

页面“跟随所选 FEE 最新文件”会在该 FEE 换文件时自动切换；手动选择历史会关闭跟随，重新勾选即可恢复。“暂停更新”只暂停图表读取，不停止后台同步；结束工控机进程才停止树莓派访问。网络或同步异常不会阻塞树莓派采集，也不会删除其原始文件。

从旧版升级时保留 config.json 和镜像目录，解压新版后重启即可。旧缓存即使只记住过 FEE 8，也会在下次扫描时自动补上其他 FEE 的最新文件，无需删除镜像或重新传已有文件。

本地文件查看模式仍可直接运行 python3 server.py --data-dir "/本地CSV目录" --open，不使用 SSH。

## 图表操作

- 六类图表以缩略卡片铺满页面：宽屏三列、普通屏幕两列、窄屏一列。每幅图左侧是时间趋势，右侧是共享纵轴范围和刻度的横向直方图。
- 点击缩略图、“放大详情”，或聚焦缩略图后按 Enter / 空格，打开大图；按“关闭”或 Esc 返回。详情中保留完整图例、浮窗、缩放滑条及时间范围、分箱和统计控件；开关详情保留所选范围、通道和统计结果，继续接收实时更新。
- 直方图按当前可见时间区间的全部有效原始数值统计频数，不用趋势图的抽样点统计。时间缩放、新增数据和区间按钮都会同步更新分布。
- 默认基线分布按原始量 1 ADC/bin，范围覆盖所选时间内全部有限值；温度、计数率及时间诊断量保留 200 个等宽 bin。可在顶部手动选择 50、100、200 或 400。同一幅图各通道共享分箱边界，以同色半透明条形叠加显示，不进行通道求和。
- 点击图例会同时隐藏对应曲线和直方图，并按剩余可见通道调整共享纵轴与分箱范围。纵轴滑条只调整可视范围，不改变直方图统计所用的时间区间。
- 滚轮缩放时间轴，图内拖动平移。所有图共享时间范围。
- 底部滑条调整横轴范围，右侧滑条调整各自纵轴范围。
- 直方图内滚轮和其下方的独立滑条可缩放“记录数”轴，图内拖动可平移。该缩放只改变频数轴的可视范围，不改变时间范围、分箱或记录数统计；数据刷新和切换 bins 后保留缩放比例。
- 在详情中调整直方图两轴范围后，点击“计算各通道 mean / σ”。各图详情下方会列出当前可见通道的 N、mean 和总体标准差 σ（分母 N，未做高斯拟合）。计算使用完整原始值，与趋势图抽样无关。
- 统计时两轴都用于筛选：原始值必须落在纵轴读数范围内，且其所属 bin 的记录数必须落在横轴记录数范围内。bin 频数先按当前时间区间的全部有效值计算，再应用两轴筛选；范围两端均包含。频数超出横轴范围的 bin 即使条形被裁剪后仍可见，也不参与 mean / σ。
- 统计结果标明时间、读数范围、bin 频数范围和 bins 数量。N=0 时 mean、σ 显示为“—”；N=1 时 σ=0。结果为按钮点击时的快照，改变范围、通道、bins 或收到新数据后会提示重新计算。
- 点击图例隐藏或显示通道；“恢复全图”恢复横纵轴。
- “全部”显示整个文件并包含后续新增数据；“最近 5 分钟 / 最近 1 小时”跟随最新记录。
- 手动缩放后固定在历史时间范围，自动更新不会跳走。
- “暂停更新”暂停后续检查，仍可缩放、查看；“立即刷新”可手动读取一次。
- 折叠区域提供主机收发耗时与 TOD 时间差诊断。

页面使用北京时间显示 timestamp_ms；tod_time 没有时区，因此按北京时间解释。命中率与基线保持原始单位，不擅自标为 Hz 或 ADC。

## 文件与资源约定

CSV 使用 UTF-8、逗号分隔，首行列名必须包含 timestamp_ms，时间戳按非递减顺序写入。支持 BOM、CRLF、带引号字段和分块写入。与原始 readback CSV 相同的字段自动映射到图表；缺少的字段显示为空。

为避免把正在写入的半行当作数据，末行写入换行符后才计入图表。字段数错误或时间倒退的行会跳过，并显示计数；数值缺失显示断点。文件被截断、同大小覆盖或替换时会重新读取。若采集器原地重写文件且文件变大，与普通追加无法完全区分，此类采集器应使用新文件名或原子替换。

后台线程保留完整数值数据，每次显示当前区间每个分桶的最小和最大值，保留尖峰；缩放后从完整数据重新取点。趋势浮窗读数对应所显示的原始点；直方图浮窗显示 bin 边界和该 bin 的原始记录数。所有统计计数均来自完整数据，不依赖绘图抽样。

服务端每次最多读取 4 MB，工控机浏览器通过 Web Worker 解析。长文件的完整数据占用工控机浏览器内存；推荐采集程序按天或文件大小分卷，可将刷新间隔设为 5–10 秒以降低更新频率。可暂停检查再选其他文件释放上一份数据。

工控机可使用现代 Chrome、Edge 或 Firefox。远端镜像模式面向 Linux 工控机，使用 Python 标准库和系统 OpenSSH，无额外架构专用二进制包；macOS 可用作开发验证环境。Windows 仅支持本地 CSV 查看模式。图表解析和绘制使用工控机的内存与 CPU，树莓派仅通过现有 SFTP 服务提供只读文件访问。

## 验证

后端与增量读文件检查（只需 Python）：

    python3 -m unittest discover -s tests

数据解析、分块写入、极值保留检查（开发环境有 Node.js 时）：

    node tests/test-worker.cjs
    node tests/test-chart.cjs

同步检查使用本机真实 OpenSSH sftp-server 的只读模式，覆盖内容不变时零重复读取、追加、半行、工控机重启续传、文件换新、断线恢复和限速。没有安装 sftp-server 的开发机将跳过此组集成检查；部署运行只需要 ssh 客户端，树莓派需要已有 SFTP 服务。

图表检查覆盖自动跟随本地新镜像、手动历史选择、断线状态提示、图例切换、bin 数量切换、两侧纵轴对齐及时间区间统计。开发检查用 Node.js，运行页面不需要安装 Node.js。尚未连接用户的树莓派实机，部署后需确认实际 SSH 登录、SFTP 子系统和 CSV 路径。
