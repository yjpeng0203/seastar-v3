# 可选旧模式：树莓派只读增量接收

将整个运行包部署在**工控机**。树莓派保持现有 DAQ、SSH 和 fee-monitor，不安装本包、NumPy 或 ROOT，不创建接收数据库或待发送副本。

## 1. 解压与填写地址

```sh
tar -xzf seastar-online.tar.gz
cd seastar-online
cp online/remote.example.json remote.json
nano remote.json
```

主要修改 `host`，例如 `pi@192.168.1.20`。`remote_dir` 默认 `/home/pi/seastar-daq/data/both`；`pattern` 默认只接收 `data_fee_3_*.dat`，板号不同请修改。配置中**不要加入密码**。

默认 `auth` 为 `password`：启动时在工控机终端输入一次，运行期间自动用于重连；程序不将密码写入配置、数据库、日志或环境变量。退出后需重新输入。密码模式使用直接 SSH 连接，不使用 ProxyJump/ProxyCommand，也不处理多因素认证或密码过期修改。已有 SSH 密钥/agent 时可改为 `"auth": "key"`，适合无人值守开机启动。

若这台工控机尚未连接过树莓派，先按正常流程执行 `ssh pi@树莓派IP`，由你核对主机指纹后退出。程序保留严格主机密钥检查，绝不自动接受未知主机或输入密码来确认主机身份。

## 2. 检查工控机环境

```sh
sh start.sh --check --remote remote.json
```

检查命令不联网、不询问密码、不编译内核、不创建数据库。运行需要 Linux/macOS、Python 3.8+、NumPy 1.19+、C++11 编译器和系统 `ssh`。Windows 使用 WSL。仅在工控机缺少依赖时由管理员安装：

```sh
sudo apt install python3 python3-numpy g++ openssh-client
```

无需 Paramiko、Node.js、npm、CDN 或工控机上的独立数据库服务。完整 ROOT 回放才需要匹配的 PyROOT；DAT 取数监控不需要 ROOT。

## 3. 启动

```sh
sh start.sh --remote remote.json --open
```

在工控机终端输入树莓派 SSH 密码，然后打开 `http://127.0.0.1:8766`。默认目录都在工控机：

```text
online/runtime/received/          本地 DAT 镜像，文件只追加
online/runtime/received/.receiver/ 接收事务水位、独占锁
online/runtime/analysis/          分析检查点、逐波形指标、编译缓存
```

不要用 sudo 运行监控；使用平时 SSH 登录的工控机账户，沿用该账户的 known_hosts。关闭终端/Ctrl+C 会停止接收和分析，树莓派 DAQ 不受程序控制。再次执行同一命令并输入密码会恢复检查点。

需要换磁盘或端口时：

```sh
sh start.sh --remote remote.json \
  --data-dir /home/ipc/disk/seastar-received \
  --state-dir /home/ipc/disk/seastar-analysis \
  --port 8766 --open
```

首次请选择**空接收目录**。程序拒绝覆盖已有非本接收器管理的同名 DAT。相对路径以运行命令时的当前目录为基准。

## 网页中的两层进度

“树莓派增量接收”显示工控机已确认落盘量、上次检查的源端未接收量、源盘空间和实际读取模式。“读取积压”则属于当前选择的本地分析 Run。两者含义不同，不把传完字节误称为分析完成。

“暂停接收”只暂停网络拉取；分析可以继续消化工控机数据。“暂停分析”不停止接收。“冻结画面”仅冻结浏览器。密码/主机密钥/文件连续性错误会停止重试；核实后可点“核查后重试”，错误密码不会无限循环尝试。

默认只从每个匹配 FEE 的最新 Run 开始，之后跟随新 Run；不主动下载全部历史。`start_mode` 可显式改为 `all`。一个分析视图选择一个 Run；镜像中的其他 Run 可在列表中切换。

## 对树莓派及 SD 卡的新增操作

- 使用一个 OpenSSH 长连接。连接期间临时执行随包提供的只读 Python 助手，断开后退出，不把脚本安装或保存到树莓派。
- 助手使用 `python3 -B`，禁止生成 `.pyc`；只使用标准库，尝试降低自身进程优先级。
- DAT 和源目录优先以 `O_NOATIME` 只读打开。实际是否成功在网页显示；权限/平台不允许时退回普通只读并提示，**不修改树莓派挂载参数或文件归属**。
- 新增字节单次顺序读取；文件数据在正常持续连接中不会反复下载。重连时仅额外读少量头尾边界校验，已追平时不重读整卷、不在树莓派进行整卷哈希或压缩。
- 默认新增数据限速 2 MiB/s、每块最多 256 KiB，追平后每秒检查当前文件，约每 10 秒重新扫描文件名/元数据。新 Run/分卷的发现延迟受扫描间隔影响；可在观察负载后调整 `scan_seconds`。
- 只读取配置目录当前层匹配的 DAT，不递归扫描树莓派磁盘；不传 ROOT/CSV，不删除树莓派文件。现有 fee-monitor 仍可继续运行。

这减少的是新增监控操作，不会消除 DAQ 原本的 SD 写入；SSH 系统认证日志、系统交换及原 DAQ 刷盘仍由树莓派管理，不能承诺整机零写卡。未在真实树莓派上测量 CPU、温度或 SD I/O，部署时应先旁路观察。

## 恢复与数据安全

工控机先写 DAT 并 `fsync`，再用 SQLite FULL/WAL 事务发布接收水位。分析端只读已提交前缀；崩溃留下的未提交尾部由接收器恢复，已提交数据不回退、不覆盖。分析指标与读取位置另在分析数据库中原子提交。

保留原文件名和分卷顺序，支持半包跨块/跨卷。源文件必须为不可回写的追加文件；inode 替换、截短、续传边界变化、已切换的旧卷再次增长等情况会停止接收，不把不同数据混合。不能检测保留原身份和边界的任意恶意中间改写；不替代硬件校验。

源盘和工控机空间都会显示/告警。工控机低于预留空间（默认 2 GiB）时暂停拉取，数据继续留在树莓派；不要无限期忽略积压，否则树莓派自身也可能填满。程序不自动清理任何源文件。

网络故障按 2、4、8…最多 60 秒退避重连，不每秒新建 SSH 登录。密码在进程内存中保留以便重连；程序重启后必须重新输入。

## 现场核查

先确认正常取数时文件列表、接收量和波形数增长，再短暂断开网络，观察接收进入重连、工控机已有数据仍可分析；恢复后确认积压下降且没有重复计数。最后检查树莓派实际读取模式、CPU/温度、原 DAQ 错误计数及剩余空间。

本包已完成本机真实加密 SSH/密码认证、83 分卷、断线重连、接收与分析重启、未提交尾部隔离及完整文件 SHA-256 核对。详情见 `online/docs/network-validation.json`；这不代表已经在你的现场树莓派完成验收。

## 常见启动问题

- 密码错误：程序会停止自动尝试。请 Ctrl+C 退出，再启动并重新输入；网页重试不会询问新密码。
- 主机密钥未知/变化：先用正常 SSH 流程核对，不要关闭主机密钥检查。
- 看不到数据：核对 `remote_dir` 和 `pattern`；读取仅限该目录当前层的匹配 DAT，默认从最新 Run 开始。
- 网页提示普通只读/可能更新 atime：目标系统或文件权限不允许 O_NOATIME。可先暂停接收，检查现场文件归属；程序不会擅自修改挂载参数或权限。
- 只使用密码但想开机自动运行：密码模式需要终端输入。无人值守自动启动应由你配置 SSH 密钥/agent，程序不把密码写入文件来绕过这一限制。

## 更新分布图设置版本

先 Ctrl+C 停止旧服务；在原程序所在父目录覆盖解压新的 `seastar-online.tar.gz`。不要删除已有 `remote.json`、`online/runtime/` 或自定义的接收/分析目录。使用原命令重启后刷新浏览器。

每张一维直方图可独立输入横轴上下限和 bin 数，点“确认”后从已保存指标精确重分箱。上一发布版在配置和数值内核相同时会恢复原分析会话，不为分箱重新解析原始波形；树莓派只继续正常的增量接收。
