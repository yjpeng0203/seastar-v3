# SeaStar 波形在线分析

在取数主机上增量读取 DAT，浏览器查看实时分析。原始数据只读；图形库离线打包。默认按 `FEE/hunt_id : ch_id` 区分通道，幅度为 ADC、积分为 ADC·sample，不假定 PMT 对应关系或 NPE 标定。

## 工控机直接读取本地 DAQ 数据

当前 DAQ 已直接写入工控机的 `/home/ipc/disk/debug/data/both`。监控也部署在工控机，只读这个目录；不再从树莓派接收或复制 DAT。完整步骤见 [DEPLOY_IPC.md](DEPLOY_IPC.md)。

```sh
tar -xzf seastar-online.tar.gz
cd seastar-online
sh start.sh --check --data-dir /home/ipc/disk/debug/data/both
sh start.sh --data-dir /home/ipc/disk/debug/data/both \
  --state-dir online/runtime/local-analysis --open
```

网页为 `http://127.0.0.1:8766`。本地模式不连接树莓派、不需要密码；只有显式传入 `--remote` 才启用 [旧的远程接收模式](DEPLOY_REMOTE.md)。运行需要 Linux/macOS、Python 3.8+、NumPy 1.19+ 和 C++11 编译器；本地 DAT 模式无需 ROOT、OpenSSH、Node.js 或 npm。Windows 可用 WSL。首次启动编译数值内核，之后复用缓存。

默认启动全部已发现串的独立后台任务，`--workers 3` 控制同时分析上限；网页切串只改变查看对象，其他串继续处理。`--single-source` 仅用于兼容单源调试。各串在 `--state-dir/strings/` 下隔离状态，父服务也使用独占锁。在线模式默认跟随各自 FEE 的新 Run，可用 `--no-follow-new-runs` 关闭；网页也可切换。现有 DAT 从头处理，追平后监听新增字节；分卷和半包沿用已有完整性检查。原始数据只读，分析状态只写到 `--state-dir`，不会创建另一份 DAT。

混合目录启动时优先读取最新 DAT 串，再处理历史 ROOT；`trigger_signal_*.dat` 为触发旁路文件，不作为波形源。暂停任务保留查看和断点，并释放分析名额，排队任务自动启动；继续已暂停任务时仍遵守 `--workers` 上限。排队串明确显示“等待计算资源”，通道与图表清空，不沿用上一串读数。更新本版本时沿用原 `--state-dir`，兼容上版波形检查点。

### Mac 或 Linux 历史回放

```sh
sh start.sh --data-dir /历史数据目录 --state-dir online/runtime/replay --replay --open
```

使用 `--replay` 固定各串当前 Run、关闭自动跟随和取数停滞告警；同一串优先选完整 ROOT，在线模式优先 DAT，避免同一采集的 DAT/ROOT 重复统计。读完显示“回放完成”；缺卷/异常跳字节/未完成尾记录另行提示。回放仍可手动切换数据源，改变参数会建立新分析会话。复用相同状态目录可恢复已有指标；不同数据集应使用各自状态目录。

扫描目录中的 `*.dat` 和 `data_*.root`，忽略 `.gz`，跳过 `results*`、`online/` 与隐藏目录。完整 ROOT 回放需要匹配的 PyROOT；优先校验并复用已完成分析的输入文件大小/修改时间、参数和内核指纹。首次无缓存时调用原生 C++ 批量分析，再建立持久化显示缓存；不再用 Python 逐事件遍历完整 ROOT。DAT 回放不需要 ROOT，不必先解压 `.gz`。完整 ROOT 回放与 DAT 是两个数据源，不会混加统计。

相对路径以执行命令时的当前目录解释。不要将本地 DAQ 输出目录设为旧接收镜像；旧镜像中的 `.receiver` 仍执行事务水位检查。

其他电脑查看工控机实时结果时，加 `--host 0.0.0.0` 并访问 `http://工控机IP:8766`；用于受控实验室局域网。查看整晚趋势请选“当前时间段全部”，默认显示当前时间段全部；也可切到最近时段。具体的 `data_1026_1027` 回放命令见部署说明：这次 `idx001.dat` 实为 gzip/tar 归档，使用同目录可用的 ROOT 回放；不要将不完整 DAT 结果当作整晚统计。

## 网页功能

- **运行概览**：原始触发数、带波形触发数、空触发数、波形数、合格占比、相对采集跨度、积压和本机实际处理能力；通道表给出累计均值。
- **实时趋势及右侧分布**：带波形触发率、通道波形率、基线、噪声、平均主积分、合格比例。时间分箱可主动设置，默认开启 100 s；点击应用后按原始记录计算每箱均值，不从旧均值重新合并。取消勾选可逐条查看原值，大范围用明确分页，不抽点。两种模式都连接相邻有效点，缺失处不填 0。右侧统计原始观测数值，独立于时间箱：分箱模式按完整所选时段，原值模式按当前原值页，与趋势共享 y 轴。横轴下方给出 CSV 锚点估算的分钟级北京时间参考，原相对时间及各项计算保持不变。
- **波形与窗口**：近期原始波形、每条波形实际积分区域、基线与噪声带、CFD 交点、平均波形、峰位对齐平均波形、波形密度图。可冻结画面检查单条样本。
- **幅度与积分**：峰高、主积分、负尾面积、基线和噪声分布；峰高与积分散点；ADC 与历史 mV/pC 标度切换；频数/归一化、logY。
- **定时与形状**：峰位、CFD、固定阈值到达时间、单脉冲 FWHM、10–90% 上升时间、90–10% 下降时间、积分窗口长度、SNR、脉冲数、同通道波形间隔、带波形触发间隔、波形头与触发头的时间差。
- **关联和质量**：同触发通道符合矩阵、同触发波形内 CFD 差、触发波形重数、逐类质量标记；文件停滞、半包、分卷缺失、重同步、时钟异常、基线漂移和低合格率提示。
- **导出**：逐波形 CSV、当前通道 CSV、显示时刻的统计/配置 JSON、各图 PNG。CSV 包含读取序号、原始整数纳秒时间、时间段、板号/通道、实际积分边界、标记和分析代码指纹。
- **运行控制**：暂停/继续当前串分析、冻结网页显示、恢复检查点、新建会话、网页调整分析参数。改变规则创建新会话并重算，不将不同规则的结果混在一起。

页面采用全宽缩略图总览；点击卡片或“放大详情”进入近全屏详情，提供该图适用的分箱、图例、缩放、logY、归一化和 PNG 导出。关闭详情保留设置。缩略图仅作显示层峰值预览，省略的箱不代表零；不合并原始计数，完整细箱在详情查询。logY 保留正计数，并对孤立细箱增加像素标记。

图形库为随项目提供的 Apache ECharts；无需 CDN、Node.js、数据库服务或前端构建步骤。`static/vendor/` 保留其许可证。

## 分布图范围与分箱

幅度、积分、负尾、基线、噪声、峰位、CFD、宽度、窗口、SNR、波形时间差、符合时间差和时间间隔等一维直方图，各自都有“横轴下限、横轴上限、bin 数”。输入后点击“确认”生效；未确认的输入不会改变图。

- 手动设置的 bin 数为 1–4096 的整数；bin 宽等于 `(上限−下限)/bin 数`。同图各通道使用同一组等宽边界。
- 默认分布直接读取与指标事务一致的持久化细箱；自定义分布从工控机已保存的逐波形指标统计（DAT 为 SQLite，历史缓存为标量 ROOT），不拆分旧粗箱，不重新读树莓派，也不重算波形。
- 上下限均包含，最右端点计入最后一箱。范围外计数和缺失值另列；N、μ、总体 σ 只针对确认范围内的有效值。
- “谱归一化”对当前范围内的样本计算每 bin 概率（计数/N），单位切换不改变纵轴。图形缩放不改变已确认的统计范围；要改变统计范围，请修改输入并再次确认。
- 已确认设置保存到当前浏览器，刷新后保留。单位切换按原始指标单位换算范围；未确认的编辑在切换单位时丢弃。
- 有新增波形指标时，默认及自定义直方图约每 5 秒刷新；只请求当前视图需要的图。冻结画面后不会继续引入新的数据水位。
- 旧版 `seastar.histograms.v1` 自定义设置不再自动套用，避免 4000 pC/4000 bins 遮盖新默认；新手动设置保存在 v2。
- “恢复自动”按原始量每单位一箱，横轴覆盖全部所选有限值：幅度、基线、噪声为 1 ADC/bin，积分、负尾为 1 ADC·sample/bin；按默认配置切换物理单位后分别为 0.5 mV/bin、0.02 pC/bin，箱数、逐箱计数保持不变。时间标量按 1 ns/bin，SNR 和脉冲数按原始数值每单位一箱。百万级空箱采用稀疏表示，自动箱数不受手动 4096 上限限制；新指标增量累计，不重复扫描全部历史。时间间隔和符合时间差保留原有自动分箱。触发重数等天然整数计数柱图保持整数统计，不把它们当连续分布拆箱。
- 时间间隔图的横轴为 `log10(间隔/秒)`，输入也使用此单位。符合时间差只取合格定时；间隔统计使用全部波形，与原有口径相同。

本次升级允许上一发布包在数值内核和配置一致时继续既有指标与读取位置。升级时停止服务、在原目录覆盖程序文件，保留 `remote.json`、`online/runtime/` 或自定义的数据/状态目录，然后重启并刷新页面；不要删除这些运行目录。

## 自适应积分规则

唯一数值实现为 `adaptive_waveform.h`。网页后端通过 ctypes 调用编译的内核，旧 ROOT 宏也直接包含同一头文件，避免两套算法分叉。

1. 短前沿区给出基线种子；用相邻差值的 MAD 估计噪声，噪声下限为 0.5 ADC，避免整数平台上除零。前沿明显不安静时寻找替代安静区，并标为 `baseline_fallback`。
2. 在**整条波形**上寻找主峰；极性可自动判断或固定为正/负。默认检测阈值为幅度至少 `5σ`。
3. 主峰两边寻找连续 3 点低于动态正向阈值 `max(1.5σ, 峰高×0.005, 0.5 ADC)` 的位置，向外扩展 2 点。穿过基线进入负尾也结束主窗，负尾不被强行包含到主窗末端。平滑仅用于找区域；积分和定时使用原始采样值。
4. 在主脉冲之前筛选安静样本、剔除异常点，重新估计基线与噪声，再定位主峰与边界。至少需要 12 个基线样本；不能可靠估计的波形保留诊断、排除默认合格统计。
5. 积分使用半开区间 `[start,end)`，不会重复计入边界点：

   `area = Σ polarity × (ADC[i] − baseline), i ∈ [start,end)`

   原始负脉冲按极性翻转后，主积分和幅度为正。导出同时保留 `polarity`；原始波形图不翻转。
6. 主区之后的显著负向分量作为 `tail_negative` 独立记录，不自动加到主积分。尾区在后续正脉冲前停止。它是诊断量，不宣称已完成交流耦合或电荷恢复标定。
7. 基于间距和谷深识别额外脉冲（计数上限 16）。主窗内重叠脉冲标为 `pileup`；主窗外的次脉冲单列 `secondary`，不会因此一律删除主脉冲。

默认规则适配本目录的两类峰位，**并不保证所有未来波形都能无人工检查地正确分割**。长脉冲、无安静前沿、严重堆积和采样范围截断会被标记；应先看实际波形与质量占比，再确定该 Run 的参数。阈值/边界规则、软件版本和指纹随结果保存。

### 质量标记

| 位 | 名称 | 默认排除合格统计 | 含义 |
|---:|---|:---:|---|
| 1 | low_snr | 是 | 主峰低于检测阈值 |
| 2 | baseline_short | 是 | 可用基线点不足 |
| 4 | baseline_drift | 否 | 基线前段与后段存在明显斜率，需检查 |
| 8 | edge | 是 | 积分区域触及采样边界 |
| 16 | clipped | 是 | 主脉冲触及配置上轨，或负脉冲触及零码 |
| 32 | pileup | 是 | 主积分窗内存在多个显著峰 |
| 64 | timing_missing | 否 | CFD 没有有效括区；定时保留为空，不填零 |
| 128 | secondary | 否 | 整条波形存在额外脉冲 |
| 256 | adc_range | 是 | 存在超过配置 ADC 上轨的码 |
| 512 | baseline_fallback | 是 | 前沿不安静，使用替代基线区 |
| 1024 | tail_clipped | 否 | 负尾触及轨道；尾部恢复量不可靠 |

“合格”是当前算法的筛选定义，不等于物理探测效率。默认频谱仅显示合格样本；可切到“全部波形·含诊断”。逐波形 CSV 包含全部样本与标记。

### 单位和定时

默认 `2 ns/sample`、`0.5 mV/ADC`、`50 Ω` 来自历史分析配置，可在网页或配置文件调整。

- `area` 的原始单位是 ADC·sample；乘 `sample_ns` 得 ADC·ns。
- `Q[pC] = area × adc_mv × sample_ns / resistance`，默认系数 0.02。网页称其“历史标度”，不冒充独立硬件标定。
- CFD 在主脉冲上升沿寻找有效的相邻点交叉括区并线性插值；交点阈高还需至少达到 `timing_snr × 噪声`（默认 3σ），否则保留为空，不给出噪声中的伪交点。10% 上升/下降时间及半高宽的相应交点也执行此检查；不跨到波形后部找无关交点。缺失交点保留为空。
- FWHM 为单条波形两个半高交点的差。CFD 分布宽度、峰位分布宽度与单脉冲宽度是不同的量。
- 所有波形内定时都以第 0 个采样点为原点；没有减去光源、线缆或电子学固定延迟。符合时间差同样未标定。
- 默认 ADC 上轨码 4095 是可调整的分析配置，不从 uint16 存储类型推断实际硬件位数。尚未发生 ADC 顶码也不能排除模拟前端饱和。

## 时间轴与原始 DAT 的新诊断

当前样例有 **39,772** 条触发头，其中 **20,210** 条没有波形；ROOT 只保留其余 **19,562** 个事件。

全 DAT 序列存在 **175 次触发头时间戳回退**，但带波形事件的时间保持单调；这说明不能无条件把所有空触发的时间戳用于同一物理时间轴。原因尚无 decoder/硬件协议证明，软件不会静默“修正”这些原始字段。

因此默认采用：

`t_rel = 当前带波形事件 trigger_ns − 本 Run 首条带波形事件 trigger_ns`

这与历史 ROOT 时间处理一致。空触发仍完整计数，单独诊断其时间异常，**不据此生成总触发率**。网页的触发率明确标为“带波形触发率”。没有波形的新记录不会凭空推进该时间轴；主机更新时间另用于停滞提示。未来若需要绝对时间，应在取数进程记录同一事件的电子学计数与主机 UTC 锚点，并验证时钟同步/漂移；本版本没有用文件名或读取时间伪造这一锚点。

真正发生在带波形事件中的时钟回退会建立新 `segment`：趋势与间隔参考重置，累计频谱继续保留，导出标明段号。各段不假装连续，不将原始计数改写为 UTC。北京时间仅在图下作为粗略参考，来自同串 CSV 的 FPGA/主机时间对应记录；过滤明显偏离中位偏移的回读，分钟级显示，缺少可用锚点时明确提示。它不构成跨串同步或绝对定时标定。纳秒绝对计数在 JSON 中用字符串保留精度，在 CSV/SQLite 中保留整数。

率按时间箱与已观察采集跨度的交集归一，末尾未填满的时间箱不除以完整箱宽；零曝光时不估计率。采集空档是否为死时间仍未知，软件不进行死时间校正。

## 增量读取、持久化与负载

- DAT 帧格式按样例全量核对：`FF12` 为 16 字节触发头；`FE` 为 16 字节波形头，后跟大端 uint16 采样值。支持 1–8192 点，不将 504 点写死为解析条件。
- 半个头/半个波形保留在缓冲区，跨分卷也可继续；文件尾不提前丢弃未完成记录。波形一旦完整即可分析，末触发的重数/符合在下一触发前标为暂定，快照不重复累加。
- 非法长度、纳秒字段和帧头会触发诊断，只在找到合法触发头后重新同步；波形字节不会任意被解释为新波形头。
- 检测 inode 更换、缩短、文件头/读取位置附近字节改变；出现时停止并要求新会话，避免重读后累计两遍。不保证检测任意位置的恶意原位改写；输入应是 DAQ 追加文件。
- 分卷按编号读取，缺卷则等待；已切换的旧分卷再发生追加时停止，防止读取顺序交错。启动时只有中间分卷会明确提示覆盖范围不完整。
- 状态目录使用操作系统独占锁，防止两个实例覆盖同一检查点；崩溃后锁自动释放。SQLite WAL 在同一事务内提交逐波形指标、原始细箱索引、统计、解析半包和读取位置；失败批次回滚，重启回放未提交部分。参数或分析代码指纹变更使用独立会话。
- 内存只保留固定数量的直方图箱、历史时间箱、最近时间箱、平均波形和抽样示例。逐波形指标在磁盘持续增长，不设静默删除策略。数据库和采集盘需预留空间，数据库写入失败会暂停分析并保留上次检查点。
- 均值、总体 σ、极值和样本数精确累计，不由直方图反推。直方图按倍增范围合并相邻箱，图形分辨率会随范围增大而变粗，总计数不变。趋势均值按样本数加权合并。
- 密度图和散点只作显示抽样；平均波形、累计指标与频谱计算不抽样。默认每 10 条合格波形取 1 条用于密度/散点，最近保存 8 条波形，散点最多 1000 个/通道。

## 文件

`server.py` 为只读数据服务与后台读取线程；`acquisition.py` 处理 DAT/ROOT；`adaptive_waveform.h` 是共享数值内核；`analysis.py` 提供编译接口与在线分布；`engine.py` 维护通道/事件统计；`storage.py` 提供事务；`static/` 为网页。

实现参考：[Python sqlite3](https://docs.python.org/3/library/sqlite3.html)、[Python HTTP 服务](https://docs.python.org/3/library/http.server.html)、[NumPy](https://numpy.org/doc/stable/)。服务面向本机/受控实验室局域网；公网部署需另行配置访问控制与反向代理。


### 工控机资源与历史缓存

已提供的 i7-12700K、31 GiB 内存工控机默认使用三个单线程分析进程。历史批量任务降低 CPU 调度优先级；同一机械盘的 DAT 按批次互斥读取，原生 ROOT 批处理按 8192 事件轮转磁盘锁，NVMe 可并读。建议将 `--state-dir` 放在 NVMe，例如 `/home/ipc/.cache/seastar-v2/analysis`；原始数据继续留在原目录。

`scripts/debug_local.sh` 正常启动不再预先扫描整批 DAT；`--verify-only` 保留完整体检。Linux 默认缓存位于 `${XDG_CACHE_HOME:-$HOME/.cache}/seastar-v2/`，可用 `SEASTAR_STATE_DIR` 显式覆盖。

历史缓存的波形平均、频谱、数值统计覆盖全部适用样本；时间趋势从逐波形指标读取，可主动设置时间箱，默认 100 s，也可切回逐条原值。分箱模式的右侧分布仍统计原始值，不统计均值点。原历史标量文件未保存的 `polarity`、`baseline_points` 在缓存 CSV 导出中留空，不填造数据；原示例波形的采集时刻未知，显示为“—”。首次冷分析未完成的 ROOT 不发布为完整结果，失败后安全重建；已完成的标量分析和显示缓存可分别复用。DAT 的增量路径保留逐批事务断点恢复。


时间分箱和数值分箱是两个独立控件。时间箱宽改变曲线的统计分辨率，默认 100 s；幅度/积分直方图仍按原始 1 ADC 或 1 ADC·sample 分箱，换单位不改逐箱计数。详情中可分别设置统计采集时段、时间箱宽、数值上下限及 bin 数。首个新时间设置会建立缓存，页面显示已用时间；原始逐波形 CSV 始终保留原值，摘要 JSON 记录已应用的时间显示设置。


### 趋势默认纵轴与原值全范围

趋势和右侧分布仍共享 y 轴，但自动视窗按当前趋势点的最小/最大值加 5% 留白设置，不再让原始分布的极值压扁均值曲线。合格比例默认固定为 0–1；常量趋势使用少量留白。数值分箱及完整计数不变。

详情的“原值全范围”可显示原始分布的全部边界，点击“按趋势范围”返回默认视窗。“恢复自动”也会退出手动范围和全范围显示。手动确认数值上下限仍按指定范围显示左右两侧。

图下显示当前共享 y 视窗及视窗外计数。自动视窗可能穿过一个数值箱；由于既有直方图未细分该箱内原始值，显示可确定的外部计数下界，并单列跨边界箱记录数，不将估算冒充精确计数。全部原始记录和直方图均保留，可切全范围检查。独立的幅度/电荷频谱范围不受此显示调整影响。


### Hz 与灰色统计误差带

主概览的彩线为各通道已记录波形计数率，黑线为带波形事件计数率，单位统一 Hz：`N / T_observed`。计数按波形所属事件的采集时刻归箱，与 ROOT 批次率图口径一致；末箱使用实际可见箱长，观测跨度不足时不造出 Hz。右侧是同一时段各时间箱计数率的数值分布，频数单位为“时间箱数”。切换其他指标到原值模式不会把该图改成间隔或平均间隔倒数。旧的毫秒读数范围不会套用到 Hz 图。

默认开启“统计误差带”，灰带位于彩色曲线后方，可关闭。计数率使用中心 68.27% Poisson 区间：N<25 用 ROOT gamma 分位数生成的常数，较大计数使用 Wilson-Hilferty 近似；零计数仍有非零上限。箱内均值用样本标准差（ddof=1）除以 sqrt(N) 得到标准误差，N<2 不虚构误差；箱内通过比例用 68.27% Wilson 区间。均值灰带不是箱内原始值 RMS 波动范围。误差假设计数/观测独立，不含标定和死时间等系统不确定度；原值模式不虚构单条测量误差。

图例隐藏系列后，自动 y 轴按可见曲线及其误差带重新取范围；手动范围仍优先。误差小于像素时不人为放大，可在详情仅选择一个通道核验。计数率悬停可查看 N、观测箱长与统计区间，均值悬停可查看有效 N 及误差范围。

定义参考：[ROOT TProfile 均值误差](https://root.cern.ch/doc/v640/classTProfile.html)、[ROOT TEfficiency Wilson 区间](https://root.cern.ch/doc/v636/classTEfficiency.html)。当前均值误差明确使用无偏样本方差估计，不与 ROOT 默认的总体 RMS 分母混用。
