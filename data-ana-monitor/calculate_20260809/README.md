# SeaStar 历史分析与修正后的 ROOT 宏

本目录保留两份历史原始 ROOT、实验汇报 PPT 和多轮 `results*` 输出。原始数据和既有结果未重写。历史结果来自不同版本/参数，不能按当前宏的默认规则解释。

新的实时网页分析、完整算法说明、增量读取与验证入口见 [../online/README.md](../online/README.md)。推荐直接用它监控增长的 DAT，或回放完整 ROOT。

## ROOT 宏的当前行为

```sh
root -l -b -q 'seastar_stringtest/data_xxx.root' 'analyze_charge.C'
```

`analyze_charge.C` 已改为直接使用 `../online/adaptive_waveform.h`，与在线工具共享同一数值内核：

- 按实际波形重估基线、主峰和积分边界，采用半开区间 `[start,end)`，不再固定前 70 点 / 第 71–200 点。
- 默认只填入通过质量筛选的波形，并在终端报告原始数与拒绝数。在线工具另保留所有波形的诊断、标记与指标。
- 负向尾部单独提取，默认关闭加和对比；不再对整个尾区净积分取绝对值，也不与主积分重复一个采样点。
- CFD 和阈值定时只使用上升沿有效交叉括区，缺失值不填 0，不越界、不除零。
- 峰位/定时范围覆盖实际波形长度；趋势坐标范围随数据调整，避免旧 420–500 ADC 基线范围隐藏当前数据。
- 率按实际覆盖时间归一；输入空树、数组不一致、混合板号、时间回退会明确报错。多板与分段时钟请使用在线工具。
- 非零首通道也能正确建立叠加图坐标；同一秒运行不覆盖已有输出目录。
- 缺少嵌套 vector 编译字典的 ROOT 环境会自动构建必要字典；生成物只写本次输出目录，避免 TTreeReader 使用未编译的 collection proxy。

宏输出保留历史 mV/pC 单位约定：`2 ns/sample`、`0.5 mV/ADC`、`50 Ω`；这不是 NPE 标定。时间演化相对首条保存触发；波形内到达时间不是已经扣除线缆延迟的本征 TT。

## 历史记录的解释

- `seastar_stringtest/data_20260624-25-IP55.root`：104,130 事件、239,733 条波形。
- `seastar_stringtest/data_LED-8ns_20260623-24-IP58.root`：852,878 事件、2,137,047 条波形。
- `results_20260624-25-IP55_V0` 对应 400–2000 mV 的历史幅度筛选；不是当前默认。
- `results_20260716_125755` 的 CFD 为 20%，后续版本为 10%。
- `results_YYYYMMDD_HHMMSS` 中的日期是执行分析时间，不是采集时间。
- 本目录两份 PPT 内容相同；只找到某次 Muon 测试的 OM66 / ch2 / 24 m 记录，没有完整 PMT 映射或电子学绝对时间基准。

旧结果仅作为历史材料，新宏重跑会输出新的 `results_*`，不承诺复现旧固定窗口的谱形和均值。新工具的验证报告保存在 [../online/docs/validation.json](../online/docs/validation.json)。
